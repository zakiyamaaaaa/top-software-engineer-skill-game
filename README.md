# ENGINEER'S GUILD — 星灯りの設計士

エンジニアリングの65項目を、ヒカリとの冒険で学ぶ日本語ブラウザゲーム。RPG風の成長システムと、選択肢で会話が変わるビジュアルノベルを組み合わせています。

## 起動

Node.js 18以上で、プロジェクトのディレクトリから次を実行します。npm installは不要です。

```sh
npm start
```

http://127.0.0.1:4173 を開いてください。停止はターミナルで Ctrl+C。ポート変更は `PORT=4180 npm start`。静的ファイルだけなので、既存の静的ホスティングでも配信できます。公開配信はまだ行っていません。

## 遊び方

- 初期のおすすめは「メモリの使い方」。13章のどこからでも始められます。
- 1章5問。選択肢は毎回シャッフルされます。数字キー1〜3でも回答できます。
- 正解は初回20XP、再回答10XP。誤答は5XPで、解説と再挑戦があります。
- 1回正解で「理解」、2回以上で「定着」のゲーム内表示になります。実務能力を保証する判定ではありません。
- 間違えた問題は即時、正解した問題は1・3・7・14・30日後に復習対象になります。
- 学習数に応じて称号と仲間の絆が成長し、0・5・15・30・65スキルで会話エピソードが開きます。
- スキル図鑑で検索、分野の絞り込み、お気に入り、個別練習ができます。
- 今日の目標は5問。連続日数が途切れても経験値は減りません。

## 2D探索と図で学ぶ流れ

- ホーム画面では、広場をクリックしなくても矢印キーでキャラクターを移動できます。広場を選ぶと WASD でも操作できます。キーを押し続けると連続で歩きます。移動方向に合わせて、正面・背面・左右の横顔の画像へ切り替わります。入力欄やダイアログ、教材の画面では矢印キーの通常操作を保ちます。
- スマホでは広場の下の方向ボタンで移動します。棚やヒカリのいるマスには入れません。
- 番号の付いた章の入口、またはヒカリの隣まで歩き、Enter / Space または出発・会話ボタンを押します。「入口の番号と章を見る」で対応を確認できます。従来の章一覧からも開始できます。
- 各章の最初に学習目標と重要な用語を示し、各問の前に技術概要、詳しい説明、コード例、よくある間違い、記述練習、図を表示します。「説明を読んだので問題へ」で選択問題に進みます。復習と個別練習も同じ流れです。
- 回答後の解説とスキル図鑑にも、日本語のラベルが付いた13章分のSVG図解を表示します。各スキルの説明文・キャプションとあわせて読めます。
- 広場の現在地は同じページ内で保持されます。再読み込みすると中央に戻ります。以前のセーブも読み込めます。

## 保存と音

回答、経験値、スキル、お気に入り、会話の選択、記述練習のメモ、設定は localStorage に保存されます。クエストの途中の画面は保存しません。戻った章で再挑戦できます。端末やURLを変える場合は設定からJSONを書き出して読み込んでください。保存不可の環境では書き出しを利用できます。

音は初期OFFです。「音 OFF」を押すとBGMと効果音が有効になります。再訪時はブラウザの自動再生制限に従い、最初の操作で再生します。タブを隠すとBGMは止まります。音量は設定で変更できます。

背景・キャラクター画像、32秒のオリジナルBGM、4つの効果音を assets に同梱しています。フォントを含め外部サービスやAPIキーは不要です。画像の生成プロンプトは docs/ASSETS.md、音の再生成は `python3 scripts/make_audio.py`。

## 開発と検証

```sh
npm test
```

- `curriculum.js`: 13章・65項目の問題と解説

## 詳しい教材と練習

全13章・65テーマに、学習目標、仕組み・使いどころの説明、具体的なコード例と読み方、よくある間違い、記述練習と回答例を用意しています。章末には、その章の知識を組み合わせる課題があります。

オブジェクト指向の章では、カプセル化・抽象化・継承・多態性の4つを説明します。継承で親の機能を引き継ぐ例と、部品を組み合わせるコンポジションの例を比較し、確認問題には判断対象のコードと各選択肢の理由を付けています。

記述練習は自分で確認する課題で、自動採点はしません。メモは入力のたびに保存され、図鑑や教材の読み直しからも確認できます。章の最後の課題にもメモを残せます。選択問題の正解数と、説明・実装できる力を分けて考え、回答例を読む前に自分の理由を書いてみてください。

教材の読み方・追加時の基準・技術資料は [docs/LEARNING.md](docs/LEARNING.md) にまとめています。

## 学習文の書き方

章名は「プログラミングの基本」など、学ぶ内容を直接示します。概要・問題・選択肢・解説・図解では、専門用語の意味を身近な言葉や具体例で説明します。「熱い経路」のような比喩や、意味を説明しない略語を避けます。新しい教材にも同じ方針を適用してください。
